# 鲸鱼娘桌宠 · 半独立部署

一只鲸鱼娘，两种活法：

- **不开 DSH**：当普通桌宠跑——待机、随机小动作、点击、拖拽、甩抛、右键菜单、多开、换动作都正常。
- **开 DSH**：DSH 自己再拉起一只（带 agent 联动的那只），显示思考 / 干活 / 等审批 / 出错 / 完成，并显示余额。关掉 DSH，这只自动退出，独立那只不受影响。

> 按你的许可：提前开着一只（无 agent）之后 DSH 再拉起第二只（有 agent），是预期行为，不会去抢同一个实例。

## 一、为什么选这个方案

对比过的候选里，只有 `mizuki5101/dsh-dafyfish-pet` 把「独立外壳 + DSH 插件拉起 + 自动发现」全做齐了，但它是个人练手项目、仅 Windows、代码里写死作者本机路径，还**不带 Live2D 模型**（模型另有非商用授权）。

最终选了 **`PC2005-cloud/dsh-pet`（4106★，MIT）**，因为它把两半都做成了一等公民：

| 需求 | 由什么实现 |
|---|---|
| 不开 DSH 可当普通桌宠 | `dsh-pet-standalone`（npm 全局安装，跑在伪宿主上，零 DSH 依赖） |
| DSH 启动时自动出现 | 插件桌面模式：DSH 启动即拉起独立透明置顶窗（`display` 默认 `both`） |
| 任务运行情况 / 审批 / 余额 | 插件监听 DSH 会话事件，切「思考/工作/整理/等待/成功/出错」+ 气泡 + 余额动画 |
| 已开着也不冲突 | 两只是各自独立的进程；README 明确允许并存（共用缓存，仅告警） |
| 关 DSH 后 | DSH 那只随宿主退出；独立那只继续留着 |

代价：两只会共用同一份配置（位置/大小会同步），且理论上可能踩 Electron 缓存（实测只是日志告警，不影响使用）。

### 3.1 图形化：鲸鱼娘桌宠助手

上面的启停 / 状态 / 隐藏 / 开机自启已经收进一个本地小程序，见 [鲸鱼娘桌宠-助手](../鲸鱼娘桌宠-助手/README.md)。

```powershell
powershell -ExecutionPolicy Bypass -File "D:\DSH交付\鲸鱼娘桌宠-助手\安装到本机.ps1"
```

装好后桌面会有快捷方式；窗口里能看状态、启停、隐藏 / 显示、开 DSH、开关自启，托盘常驻。

## 四、为什么有时画面上会有 3 只

`dsh-pet` 的 `display` 字段控制同一只宠物出现在哪：

| `display` | 效果 |
|---|---|
| `both` | 桌面透明窗 **+** DSH 页面右下角内嵌，各一只 |
| `desktop` | 只出桌面透明窗（**现在用的这个**） |
| `web` | 只出 DSH 页面内嵌 |
| `none` | 都不显示 |

所以"3 只"= 独立桌宠（桌面窗口）+ DSH 桌面窗口 + DSH 页面内嵌。已经通过接口把用户层配置改成 `desktop`，网页里那只不再生成。

改完如果页面里还残留一只，按 **Ctrl+R 刷新 DSH 窗口**（或重启应用）即可。想恢复"网页里也有"就把它改回 `both`。

## 五、激活 DSH 侧

插件装进 profile 后本应重启 DSH 才加载，但本机实测：安装完成后 DSH **热加载**了插件，桌宠已经出现并连上（当前能读到余额和 `working` 状态）。

如果哪天重启后没自动出现，按下面顺序处理：

1. 完全退出 DeepSeek Harness（关窗口后确认托盘/任务管理器里 `DeepSeek Harness.exe` 也退出）；
2. 重新打开应用；
3. 打开任意会话跑一句，桌宠应切到「工作」状态；有审批时会冒「等你确认」的气泡。

> 如果重启后还是没出现：先运行 `检查状态.ps1` 看插件是否被识别；再检查 `%APPDATA%\dsh-pet-electron-helper` 是否可写、控制台有没有 Electron 相关报错。

## 六、想调外观 / 行为

配置文件（不存在时用包内默认）：

```
%USERPROFILE%\.dsh\dsh-pet\main-config.jsonc
```

常用字段（`pets[]` 里）：

- `size`：宽度像素（高度自动 9/16）；
- `display`：`web` / `desktop` / `both` / `none`；
- `position`：`corner`（`top-right` 等）+ `marginX` / `marginY`；
- `workStatusEnabled`：任务状态联动；
- `balanceEnabled`：余额动画与气泡；
- `whisperEnabled`：碎碎念（会调用模型，介意耗 token 可关）。

改完在桌宠右键菜单点「重载配置」即可，不必重启 DSH。

## 七、卸载

```powershell
# 1) 停掉独立桌宠
powershell -ExecutionPolicy Bypass -File .\停止桌宠.ps1

# 2) 移除插件（两个 profile 都清）
& 'D:\dsh桌面版\resources\runtime\cli\bin\dsh.cmd' plugin --profile desktop remove dsh-pet
& 'D:\dsh桌面版\resources\runtime\cli\bin\dsh.cmd' plugin --profile web remove dsh-pet

# 3) 卸载独立版
npm uninstall -g dsh-pet

# 4) 可选：删掉用户配置与缓存（会丢位置/记忆）
#    %USERPROFILE%\.dsh\dsh-pet
#    %APPDATA%\dsh-pet-electron-helper
```

卸载后重启 DSH 生效。

## 八、已知限制

1. **两只同屏**：这是你允许的方案。两只启动时都在右上角（同一份配置），会短暂重叠——拖开其中一只即可；它们平时会自己走动，不会一直黏在一起。若哪天想合成一只，需要给独立版加"附着 DSH"的控制口（见上一份调研的 B 方案）。
2. **共用配置**：两只的位置/大小来自同一份 `main-config.jsonc`，拖其中一只并重开另一只，位置会跟过去。
3. **缓存告警**：启动日志里可能出现 `Unable to move the cache` / `Gpu Cache Creation failed`，是两者共用 `%APPDATA%\dsh-pet-electron-helper` 造成的，可忽略；若真出现画面异常，删掉该目录再启动。
4. **兼容性标记**：插件声明的兼容上限是 DSH `0.2.1-rc.2`，本机是 `rc.3`（unknown）。实测 web profile 拉起正常；桌面端若弹兼容提示，允许加载即可。
5. **Electron 体积**：`%USERPROFILE%\.dsh\electron` 约 200 MB，删掉后下次启动会重新下载。
