## 一、三句话结论

1. **“鲸鱼娘”= DeepSeek 的娘化形象**（DeepSeek 鲸鱼 logo 拟人）。围绕她的桌宠项目，绝大多数是 **DeepSeek Harness（DSH）插件**，也就是装进 DSH Web 界面 / 桌面客户端里、浮在右下角的小宠物。
2. 生态已经分层：**DSH 插件**（主流，几十上百个）→ **独立桌面宠物**（脱离 DSH 单独运行的 exe / App）→ **移动端移植**（Android、Steam Deck）→ **素材 / 人设 / 皮肤**（不是宠物本体，但都在同一个创作圈）。
3. 头部非常集中：**余额挂件** `MeteorNOX` 6064★、**桌宠本体** `PC2005-cloud/dsh-pet` 4106★、**鲸鱼娘皮肤** `Small-tailqwq/dsh-deep-whale` 2861★。想“装一个就能用”，从这三个里选基本不会错。

## 四、避坑提示

1. **别混装同类**：多个皮肤/挂件/桌宠插件同时装容易冲突（README 明确提醒 `dsh-web` 皮肤与官方桌面版皮肤不通用；余额挂件的 npm 版与 `github:` 版会并存冲突）。
2. **许可要看细**：代码多为 MIT，但**立绘常是 CC BY-NC-SA 4.0（禁止商用）**，例如 `crosspet`、`Small-tailqwq` 的皮肤。要商用先确认素材授权。
3. **仓库很大**：`dsh-pet` 约 136 MB、`dsh-pet-indesktop` 约 187 MB、`WhaleIsle` 约 384 MB（多为动画素材），clone 前注意磁盘与网速。
4. **star 不等于质量**：这批仓库 star 增长很快，且大量是同一素材的不同 fork；挑“最近还在推 commit + 有 Release + 有 issue 回复”的更稳。
5. **“鲸鱼娘”相关的不都是桌宠**：搜索会混入皮肤、余额挂件、人设 skill、素材库，甚至完全无关的仓库（如书籍清单）——已在本报告的人工筛选里剔除。
